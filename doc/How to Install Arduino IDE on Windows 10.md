# How to Install Arduino IDE on Windows 10

English | [中文](./如何在%20Windows%20上安装%20Arduino%20IDE.md)

The first step in your Arduino journey is installing the required software.
This tutorial shows how to install Arduino IDE on Windows 10.

## Step 1: Go to Arduino Website
- Open [www.arduino.cc](https://www.arduino.cc/) to download the software.
- Hover on `Software`, then click `Downloads`.

## Step 2: Click the Download Link
- Scroll to find `Windows installer`, then click it.

## Step 3: Start Download
- You may see a donation page.
- You can donate, or click `Just download` to continue.

## Step 4: Start Installation
- Open the downloaded installer file.
- Accept the license agreement by clicking `I agree`.

## Step 5: Select Components
- Keep all default options if you are not sure what to choose.
- Click `Next`.

## Step 6: Choose Install Path
- Choose the install path for Arduino IDE.
- The default path is fine for most users.
- Click `Install`.

## Step 7: Finish Installation
- Wait for installation to complete.
- Click `Close` to exit setup.

## Step 8: Launch Arduino IDE
- Open Arduino IDE from the desktop shortcut, or search from the Start menu.
