# How to Use GitHub Desktop

English | [中文](./如何使用github桌面程序.md)

## 1. Installation
### 1.1 Download
- Download GitHub Desktop from the official website.

### 1.2 Install
- GitHub Desktop usually installs quickly after you run the installer.
- Sign in with your GitHub account after installation.

## 2. Create a New Repository
### 2.1 Create Local Repository
- Open `File -> New repository`.
- Enter repository name, choose local path, then click `Create repository`.

### 2.2 Publish Local Repository
- Click `Publish repository`.
- Confirm repository information and choose whether it is private.
- Open your GitHub page and check whether publishing succeeded.

## 3. Clone Remote Repository to Local
### 3.1 Clone
- Open clone dialog: `Clone -> Repositories`.
- Select the target repository and wait for cloning to finish.

### 3.2 Edit and Commit
- Edit files with your preferred editor.
- Return to GitHub Desktop and review changed files.
- Click `Commit to master` (or your current branch) to commit.
- Then click `Push origin` to upload commits.

## 4. Notes
- If you prefer a mixed workflow of editing + Git operations, VSCode is also a good choice.
- For example, you can write Markdown in Typora, then use VSCode or GitHub Desktop to commit and push.
