# How to Install VSCode + PlatformIO

English | [中文](./如何安装%20VScode+Platformio.md)

## Install Git Bash
- Please download and install the correct version of [Git](https://git-scm.com/downloads) first.
![image](https://user-images.githubusercontent.com/25599056/61577177-58dcb400-ab16-11e9-8167-a14fba8e2c0c.png)

## Install VSCode and PlatformIO for Compilation
- Download VSCode from [here](https://code.visualstudio.com/Download).
- Choose the installer that matches your operating system (for example, `Windows 7, 8, 10 User Installer 64bit` for a 64-bit Windows system).
![image](https://user-images.githubusercontent.com/25599056/56638014-a4aac900-669f-11e9-8694-d9e4af6ad93a.png)

- After downloading, double-click to install. Then open VSCode.
- Install the PlatformIO extension: click extension panel `①`, search `PlatformIO` in `②`, then click `③ Install`.
![image](https://user-images.githubusercontent.com/25599056/56638076-c5731e80-669f-11e9-82b9-4b21407df320.png)

- After installation, click `Reload`.
![image](https://user-images.githubusercontent.com/25599056/56638101-d328a400-669f-11e9-8406-1b2d479b8e9a.png)

- VSCode will then prompt to install PlatformIO Core (this takes a little time).
![image](https://user-images.githubusercontent.com/25599056/56638125-dcb20c00-669f-11e9-82df-79c4581a43a8.png)

- After PlatformIO Core is installed, reload again. PlatformIO is now ready.
![image](https://user-images.githubusercontent.com/25599056/56638133-e2a7ed00-669f-11e9-8951-b953b0b1bddb.png)

- In the lower-left corner of VSCode, you will see the PlatformIO icon (`①`). Click `② Open Project` to open your project.
![image](https://user-images.githubusercontent.com/25599056/56638145-ea679180-669f-11e9-9c1e-5cae6ce0d29f.png)
