# 如何在 Windows 上安装 Arduino IDE

[English](./How%20to%20Install%20Arduino%20IDE%20on%20Windows%2010.md) | 中文

使用 Arduino 开发板开始电子项目的第一步，是先安装必要的软件。
本教程演示如何在 Windows 10 上安装 Arduino IDE。

## 步骤 1：访问 Arduino 官网
- 打开 [www.arduino.cc](https://www.arduino.cc/)。
- 鼠标悬停在 `Software`，点击 `Downloads`。

## 步骤 2：点击下载链接
- 向下滚动，找到 `Windows installer` 并点击。

## 步骤 3：开始下载
- 页面可能跳转到捐赠页。
- 你可以选择捐赠，或点击 `Just download` 直接下载。

## 步骤 4：开始安装
- 打开已下载的安装程序。
- 在许可协议页面点击 `I agree`。

## 步骤 5：选择安装组件
- 如果不确定如何选择，建议保持默认选项。
- 点击 `Next`。

## 步骤 6：选择安装路径
- 选择 Arduino IDE 安装路径。
- 一般保持默认路径即可。
- 点击 `Install`。

## 步骤 7：完成安装
- 等待安装完成。
- 点击 `Close` 结束安装向导。

## 步骤 8：启动 Arduino IDE
- 可通过桌面快捷方式启动，或在开始菜单中搜索 `Arduino IDE`。
