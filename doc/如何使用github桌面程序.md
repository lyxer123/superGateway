# 如何使用 GitHub Desktop

[English](./How%20to%20Use%20GitHub%20Desktop.md) | 中文

## 一、安装
### 1. 下载
- 从 GitHub Desktop 官网下载安装包。

### 2. 安装
- 运行安装包后，GitHub Desktop 会自动完成安装。
- 安装完成后登录你的 GitHub 账号。

## 二、新建仓库 Repositories
### 1. 本地仓库创建
- 打开 `File -> New repository`。
- 输入仓库名，设置本地路径，点击 `Create repository`。

### 2. 本地仓库发布
- 点击 `Publish repository`。
- 在弹窗中确认仓库信息，并选择是否为私有仓库。
- 到 GitHub 网页端检查发布是否成功。

## 三、克隆远程仓库到本地
### 1. 克隆仓库
- 打开克隆对话框：`Clone -> Repositories`。
- 选择目标仓库，等待克隆完成。

### 2. 编辑与提交
- 使用你习惯的编辑器修改文件。
- 回到 GitHub Desktop 查看变更内容。
- 点击 `Commit to master`（或当前分支）提交。
- 然后点击 `Push origin` 推送到远程仓库。

## 四、使用建议
- 如果你希望把编辑和 Git 操作结合得更灵活，也可以使用 VSCode。
- 例如先在 Typora 写 Markdown，再用 VSCode 或 GitHub Desktop 完成提交与推送。
